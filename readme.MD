# CyberSec-Labs

Een verzameling van cybersecurity projecten die ik bouw terwijl ik Python en cyber security leer.

Deze projecten zijn ENKEL bedoeld voor educatieve doeleinden en worden uitsluitend gebruikt in gecontroleerde omgevingen.

## Projecten

| Project | Beschrijving | Status |
|---|---|---|
| MAC Address Changer | Het MAC-adres van een netwerkinterface wijzigen en controleren | Voltooid |
| Netwerkscanner | Apparaten binnen een netwerk ontdekken | Gepland |
| Packet Sniffer | Netwerkverkeer onderscheppen + analyseren | Gepland |
| ARP Spoof Detector | Mogelijke ARP spoofing detecteren | Gepland |
| Kwetsbaarheidsscanner | Mogelijke kwetsbaarheden detecteren | Gepland |

## Doelen

- Mijn Python skills verbeteren
- Meer leren over Security
- Praktische ervaring opbouwen met Python en Cybersecurity
- Leren werken met GitHub
- Voortgang documenteren

## Let op !!

Deze projecten zijn gemaakt voor leerdoeleinden en om mijn kennis en vaardigheden in het domein van Python programmeren en Cybersecurity te ontwikkelen.

Indien je deze tools gebruikt, gebruik ze dan ENKEL op systemen en netwerken waarvoor je toestemming hebt om te testen.

De gebruiker is zelf verantwoordelijk voor het gebruik van deze programma's.
Ik ben niet verantwoordelijk voor schade, verlies, misbruik of andere negatieve gevolgen door gebruik van deze projecten.

Gebruik kennis om te leren, niet om schade aan te richten. Begrijp de kracht, respecteer de impact van de kracht. Handel verantwoordelijk.
